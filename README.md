# Pixel Flag Creator

Pixel Flag Creator is a browser-based pixel art editor built using HTML, CSS, and JavaScript. Users can design custom flags, create pixel artwork, experiment with colors, and challenge the built-in flag recognition system.

The application combines creativity and interactivity by allowing users to draw directly on a pixel grid, load flag templates, identify national flags through pattern matching, and export finished creations as PNG images.

## Features

- Interactive pixel-art editor
- Multiple grid sizes
  - 16 × 16
  - 32 × 32
  - 48 × 48
- Click and drag painting
- Pencil tool
- Eraser tool
- Fill tool
- Custom color picker
- Predefined color palette
- Live artwork preview
- PNG export functionality
- Undo and redo support
- Grid line toggle
- Flag templates
- Flag recognition system
- Similarity score calculation
- Top match suggestions
- Responsive design

## Flag Recognition

The application includes a built-in recognition system capable of identifying multiple national flags through pattern analysis.

Features include:

- Color tolerance matching
- Pattern-based recognition
- Similarity scoring
- Top match predictions
- Flag identification results
- Celebration effects for successful matches

The system analyzes:

- Horizontal stripe patterns
- Vertical stripe patterns
- Color regions
- Flag structure
- Overall layout composition

Rather than relying on exact RGB values, similar shades are grouped into broader color categories for more accurate recognition.

## Templates

Includes quick-start templates for several national flags, allowing users to modify and customize designs before creating their own artwork.

## Statistics Panel

Track information such as:

- Grid size
- Colored pixels
- Unique colors used
- Completion percentage
- Current tool
- Selected color

Statistics update in real time while drawing.

## How To Use

1. Select a drawing tool.
2. Choose a color.
3. Draw directly on the pixel grid.
4. Use templates as a starting point or create a design from scratch.
5. Check the Flag Recognition section for possible matches.
6. Export your artwork as a PNG image.
